## 使用方式

### 如何触发命令执行

发送一封邮件到运行此服务的邮箱地址，**邮件正文中包含以 `@` 开头的行**即可触发命令执行。

#### 基本命令

```
@ls -la
```

服务器将执行 `ls -la`，并将输出通过邮件回复给你。

#### sudo 命令

如需 sudo 权限，在命令的下一行提供密码：

```
@sudo ls /root
your_sudo_password
```

#### 多个命令

可以发送多个命令，所有以 `@` 开头的行会依次执行并合并结果回复：

```
这是普通文字
@ls -la
另外这是一条不执行的命令
```

### 判断是否执行的条件

服务会检查以下所有条件，全部满足才执行命令：

1. **发件人白名单**：发件人邮箱或域名需在 `ALLOWED_SENDERS` 或 `ALLOWED_DOMAINS` 中
2. **正文必须以 @ 开头**：邮件正文首行必须是以 `@` 开头的命令行
3. **命令在白名单内**：仅允许安全命令（如 ls, cat, df, ps 等）
4. **未超过频率限制**：每个发件人每分钟最多 10 封命令邮件
5. **邮件大小正常**：不超过 `MAX_EMAIL_SIZE`（默认 1MB）

**重要**：如果正文不以 `@` 开头，或者 `@` 出现在中间/后面，服务将**不执行任何命令，也不回复任何邮件**。

多命令支持：如果有多行以 `@` 开头，将依次执行所有命令，并合并结果回复。

### 示例

**成功执行：**
```
邮件正文：
@df -h

回复：
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       100G   30G   70G  30% /
```

**不执行（正文不以 @ 开头）：**
```
邮件正文：
你好，这只是普通邮件

结果：不执行，不回复
```

**不执行（@ 不在第一行）：**
```
邮件正文：
这是前缀文字
@ls -la

结果：不执行，不回复
```
