## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置

首次启动时会**自动生成** `.env` 模板文件，位于项目根目录。直接编辑即可：

```bash
# 编辑 .env 文件，按需修改配置
vim .env
```

修改后重启服务生效。

**模式一：自建 SMTP 服务器（默认）**

`.env` 中默认已启用 SMTP 模式，无需额外配置，直接启动即可在 `0.0.0.0:9930` 监听邮件。

**模式二：使用已有邮件服务器（POP3/IMAP）**

编辑 `.env` 文件：

```ini
# 切换到 POP3 或 IMAP 模式
RECEIVE_MODE=imap

# 配置收件服务器
MAIL_IN_HOST=imap.qq.com
MAIL_IN_USER=your_email@qq.com
MAIL_IN_PASS=your_auth_code
# MAIL_IN_PORT 留空会根据协议和 TLS 自动选择
```

### 3. 启动服务

```bash
python main.py
```

- **SMTP 模式**：服务将在 `0.0.0.0:9930` 监听邮件。
- **POP3/IMAP 模式**：服务将按 `MAIL_POLL_INTERVAL`（默认 10 秒）轮询检查新邮件。

日志同时输出到标准输出和 `mail_command_bot.log` 文件。
